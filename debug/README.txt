=========================================
 OpenFileRescue - Debug Build (النسخة التجريبية)
=========================================

App Name: OpenFileRescue
Package: com.example
Version Name: 1.0
Version Code: 1
Build Type: Debug APK
File: app-debug.apk / debug.apk

الميزات المدمجة في هذه النسخة:
1. استرجاع وقراءة بطاقات SD وفلاشات USB OTG التالفة التي يرفض أندرويد فتحها ويطلب تهيئتها.
2. التسلسل المزدوج التلقائي:
   - المحاولة الأولى: قراءة نظام الملفات مباشرة وتجاوز حظر أندرويد عبر UsbMassStorageDevice.
   - المحاولة الثانية: استخراج القطاعات الخام عبر SCSI Block Device بمحرك FileCarverEngine عند تلف جدول الأقسام (RAW).
3. معالجة القطاعات التالفة فيزيائياً (Bad Sectors) والقفز التلقائي دون توقف الفحص.
4. استخراج التواقيع الرقمية للصور (JPEG, PNG) والمستندات (PDF) والفيديوهات (MP4).
5. شريط تقدم لحظي وعداد رقمي لعدد الملفات المسترجعة في واجهة التطبيق.
6. دعم صلاحيات سيزوكي (Shizuku) للمسارات المحمية.
